# Pratham's Cyber Canvas

Build a personal portfolio website for a backend developer named Pratham Hapani.

GOAL

A bold, high-energy, "crazy UI" single-page portfolio — not a template-looking

resume site. Think: glitch/cyberpunk or neo-brutalist energy, big kinetic

typography, unexpected hover states, smooth scroll-triggered animations,

gradient/mesh backgrounds, maybe a custom cursor. It should feel like a

statement piece, not a corporate one-pager.

DESIGN DIRECTION

- Dark theme base with one loud accent gradient (e.g. purple → blue → pink)

- Big, confident type (Space Grotesk / Clash Display / Fira Code for

  code-flavored accents)

- Scroll-triggered reveal animations (Framer Motion / GSAP if using React)

- Micro-interactions on hover: buttons, project cards, skill tags

- Subtle grain/noise texture or animated gradient blobs in the background

- Fully responsive — the "crazy" effects should degrade gracefully on mobile

TECH

Build as a single-page React app (or plain HTML/CSS/JS if simpler),

mobile-responsive, no backend required — this is a static personal site.
